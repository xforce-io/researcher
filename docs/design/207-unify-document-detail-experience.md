# 统一文档详情页阅读与操作层级

状态：Draft。对应 [#207](https://github.com/xforce-io/researcher/issues/207) 与 [L1](https://github.com/xforce-io/researcher/issues/207#issuecomment-5665638172)。

## 1 背景

#203 已把 paper / 自主笔记 / 视频收到同一套头部与按需 topic 面板。blog 与 paper 共用详情渲染。当前固定顶栏遮住 `#annotations`；「文档批注」与「重新深读」同为实心主按钮；深读进行中默认铺开英文步骤与等宽日志；paper/blog 右栏空卡片与主栏同高，长文滚动后只剩留白；身份字段与状态中英混排。本设计只收口阅读与操作层级。

## 2 名词解释

沿用 [名词表](../glossary.md) 的文档、paper、自主笔记、视频、topic 关联、文档批注、深读记录、深读产物。本设计新增：

| 规范名 | 一句话定义 | 禁止别称 |
|---|---|---|
| 页内锚点偏移 | 详情页 hash 跳转后，目标首行与固定顶栏下沿之间必须留出的可见空隙。 | scroll padding、吸顶补偿 |

blog 不是新术语，是文档的一种平级类型，详情走与 paper 相同的外部材料阅读面。

## 3 目标与非目标

目标：四类详情页共用同一信息架构与操作主次；paper/blog 的文档批注跳转后标题可见；深读三态可判且不压正文；长文三位置主栏与右栏都可用；公共文案为简体中文。

非目标：不改文档内容、深读产物、深读或视频分析能力；不为自主笔记和视频新增文档批注写入（API 仍 422）；不重做 Library 列表；不改公共 API/CLI；不更换现有 ink & paper 皮肤。

## 4 能力

### 4.1 UI/UX

**信息架构（四类相同顺序）**

```
固定顶栏（品牌 / Library / Topics）
← Library
标题（完整、可换行、不截断）
元数据一行：类型 · YYYY-MM-DD · 状态
操作行：主操作 | 次操作 | 管理 topic 关联     已关联 topic 芯片 | 尚未关联 topic
（仅外部材料深读进行中/失败：紧凑状态条，默认无日志）
主阅读面
类型附属（paper/blog：文档批注；视频：播放器+台词；笔记：正文即主阅读面）
```

**操作主次**

| 类型 | 主操作（实心） | 次操作（描边） | 弱操作 |
|---|---|---|---|
| paper / blog | 深读 / 重新深读 | 文档批注（页内跳转，非实心） | 管理 topic 关联 |
| 自主笔记 | 编辑笔记 | — | 管理 topic 关联 |
| 视频 | 视频分析（分析中禁用并改文案「分析中…」） | 编辑标题 | 管理 topic 关联 |

同一操作行不得出现两个实心主按钮。文档批注只在 paper/blog 出现，带批注数量后缀；note/video 不出现该入口，也不出现空的批注主按钮。

**页内锚点（S1）**

- 目标：`#annotations`（及详情页其它 hash 目标）跳转后，对应标题或首行完整露在顶栏下方，不得被遮住。
- 空隙：不小于顶栏实际高度 + 16px。用与顶栏绑定的同一变量，禁止写死 18px 这种小于顶栏的值。
- paper 与 blog 必须可从头部「文档批注」跳到 `#annotations`。
- note / video 无批注锚点；若页面存在其它 id 定位，共用同一偏移。不得为通过验收而做失效跳转。

**深读运行态（S3，仅 paper/blog）**

| 状态 | 用户看见 | 明确不看见（默认） |
|---|---|---|
| 进行中 | 一行：深读中 + 一句中文说明；正文仍在下方可读 | 等宽英文步骤列表、运行日志、禁用的「深读」主按钮占位 |
| 成功 | 元数据为「已深读」；操作为「重新深读」；无运行条 | 残留的成功横幅或日志 |
| 失败 | 一行：深读失败 + 可重试；失败原因可读但不铺满主栏 | 默认展开的英文日志 |
| 已中断 | 一行：深读已中断 + 「重试深读」 | 与进行中相同的步骤/日志 |

运行详情（步骤、日志）只允许放在默认折叠的「运行详情」里；打开后也不应高于约 120px 的日志窗，不得把正文挤出首屏。英文阶段名若出现，只在该折叠区内。

**长文布局（S4，paper/blog）**

- 主栏持续获得阅读宽度；右栏是贴顶栏下沿的粘滞旁注，不随正文被拉成同高空列。
- 旁注不使用「空内容大卡片」：无集成记录时一句「尚无集成记录」即可；删除入口是旁注底部的弱危险操作，不是与正文争视觉重量的大白盒。
- 开头 / 中段 / 靠后三处：主栏可读，旁注仍可见或仍承载删除/集成信息，不得只剩大面积无意义留白。
- 自主笔记保持约 760px 居中阅读列。视频保持播放器+台词工作台，本条不要求改成双栏旁注。

**文案与层级（S5）**

- 类型：论文 / 博客 / 自主笔记 / 视频。
- 状态：未深读、深读中、已深读、深读失败、已保存、未分析、分析中、已分析、分析失败、内容缺失。禁止在头部再堆 `read · 0 links · 0 integrated` 这类英文串。
- 身份字段（仅外部材料阅读面内）：作者、编号或 arXiv、来源、PDF、标签。无标签写「无」，不写 `none`。不在身份表重复状态行。
- 深读产物文件名不出现在阅读面标题旁；需要时放旁注。
- 批注类型：普通 / 澄清 / 注意 / 想法 / 问题。
- 规范名（topic、Library）与原始论文标题、台词原文保留。

**全状态（用户可判）**

- 空 topic：尚未关联 topic。
- 无深读产物：一句「尚无深读产物，可点击深读开始。」，不是空白卡片墙。
- 无批注：批注区空态一句，头部仍显示「文档批注」。
- 视频无台词 / 无语音 / 媒体缺失：沿用现有独立状态，不改业务语义。
- 错误：topic 保存失败留在面板内；深读失败在紧凑条内；标题过长仍走既有校验。

**窄屏**

- 900px 以下：paper/blog 单列，旁注改到主栏之后，不再并排留白。
- 操作行允许换行，主按钮仍可点。视频上下排列，无横向溢出。

## 5 思路与折衷

签名选择：阅读面是主角，chrome 退成页边。放弃把文档批注做成实心主按钮（它只是页内跳转）。放弃默认展开运行日志（那是实现细节）。放弃右栏空卡片撑满网格高度（那是布局副作用，不是信息）。放弃给 note/video 补空批注区来凑四种类型的锚点数量。

保留 #203 的公共头部、按需 topic 面板、视频工作台和笔记居中列。不换字体、不换底色。

## 6 架构

分层：服务层仍按文档类型装数据；视图负责公共头部、操作主次、类型正文与旁注；CSS 负责顶栏变量、锚点偏移、粘滞旁注与运行条；已有 `document-detail.js` 只管 topic 面板；深读 SSE 脚本只更新紧凑状态，日志进折叠区。

主路径：GET 详情 → 渲染公共头部与类型阅读面 → 用户阅读或点主操作 / 批注跳转 → 既有写接口 → 刷新后展示结果。

失败路径：写接口拒绝 → 原输入与错误留在原位；深读失败 → 紧凑失败条 + 重试；媒体缺失 → 只读状态，不伪装可播放。

## 7 模块

`src/web/views.ts` 公共头部、操作、深读条、身份字段、批注文案；`src/web/static/app.css` 顶栏高度变量、锚点偏移、操作层级、粘滞旁注；深读进度脚本只改默认可见文案。服务层与存储接口不变。

## 8 API/CLI

N/A：不新增或修改公共接口。文档批注、深读、关联、标题、笔记、分析请求契约保持原样；自主笔记与视频的批注写入仍 422。

## 9 边界

动态文本转义不变。高亮与台词不当 HTML。topic 面板焦点与 Escape 行为保全 #205。成功提示不跨文档串用。关联不改媒体指纹、台词、批注或深读产物。

## 10 迁移/兼容/回滚

无数据迁移。仅前端呈现。回退代码即回到旧层级，不回滚用户数据。

## 11 测试计划

E2E：隔离 workspace 含 paper、blog、note、video；桌面 1366×768。S1 paper/blog 点文档批注后标题可见，四类页面顶栏不压标题。S2 四类主次操作可辨，无异常大型空白容器，执行一个可用操作。S3 深读中/成功/失败默认可判且无默认英文日志。S4 长文开头/中段/靠后旁注仍可用。S5 四类中文层级。窄屏 paper/blog 单列可达。保全 #203 关联面板、#194 标题长度、#200 视频可见、#205 焦点。

Integration：四类渲染含公共头部；paper/blog 含 `#annotations` 且跳转控件非实心主按钮；进行中 HTML 默认不含可见的 stage 列表与 log；身份字段中文键。

Unit：状态与类型中文映射；批注类型中文。
