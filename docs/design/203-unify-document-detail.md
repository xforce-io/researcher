# 三类文档详情体验统一

状态：Approved。2026-09-13 用户在会话审阅 L1 后回复「go」，授权按提案继续；本文细化已批准范围。

## 1 背景

[#203](https://github.com/xforce-io/researcher/issues/203)；[L1](https://github.com/xforce-io/researcher/issues/203#issuecomment-5654068774)。三类详情入口和管理布局分离，视频头部表单压缩观看空间。

## 2 名词解释

沿用 [名词表](../glossary.md) 的文档、自主笔记、paper、视频、台词、中文台词、topic 关联和文档批注，无新增领域术语。

## 3 目标与非目标

统一识别与管理体验，内容优先。非目标：Library 列表重做、其它类型完整改版、数据迁移、API/CLI 更改、分析算法与新增批注能力。

## 4 能力

### 4.1 UI/UX

共同顺序为返回 Library → 完整标题 → 类型/日期/适用状态 → 操作与已关联 topic 概览 → 主内容。标题可自然换行，不截断；无标题显示类型对应占位。公共日期 YYYY-MM-DD，未知日期显示明确占位。按钮、边框、圆角与焦点规范共用，公共界面使用简体中文，规范名与原始内容保留。

头部提供「管理 topic 关联」入口。已有关系显示紧凑概览，空为「尚未关联 topic」。入口打开同一模态面板，列出关系、编辑/解除、推荐和手动关联表单；默认关闭，不占正文布局。键盘 Escape 或关闭按钮可关闭并回到触发按钮，打开时焦点进入面板，Tab 不离开面板。通过已有 edit 查询参数进入时直接打开；关闭结束本次编辑语境。提交中防重复，失败保留输入并在面板内显示错误；成功回到详情，关系变化与成功提示可见。推荐仍只填写候选，不自动提交，分数标明为匹配分。

自主笔记采用约 760px 居中阅读列；编辑入口移至头部，沿用独立编辑器与未保存保护。paper 保留深读产物、文档批注与必要侧栏能力，关联表单迁至公共面板；深读操作和批注跳转位于头部，来源和身份信息保留。视频使用宽内容区，桌面左右为播放器和台词；头部紧凑，主区域占剩余视口，台词独立滚动。窄屏上下排列且不出现横向溢出，极长标题/错误内容允许头部受限滚动，保证主区域可见。

视频标题默认大标题，「编辑标题」显式展开输入与保存/取消。201 个 Unicode 码点仍允许输入并送达既有校验；保存失败不丢输入，取消恢复原标题，成功标题与列表一致。视频分析按钮、运行中/失败/不可用原因可辨；媒体缺失时台词保留可搜、恢复入口保留；无台词、无语音各给独立状态。

搜索匹配原文和中文台词，大小写不敏感，词级高亮使用安全文本节点；当前命中采用边框，播放台词采用底色与左标记，两种状态可共存。无命中显示明确空状态，上下结果按钮在无查询或无命中时禁用；清空恢复全部台词。点句和结果切换定位到起点并播放，手动滚动暂停自动跟随的既有语义保留。

## 5 思路与折衷

复用共同头部和关联组件，保留类型正文。放弃强制全页面同宽与永久管理栏；用一次显式打开换取默认阅读空间。保留已有业务状态差异，不把保存、分析与深读虚构为同一流程。具体组件拆分不引入框架或新依赖。

## 6 架构

服务层继续按文档类型加载视图数据；服务端视图负责公共头部、类型正文及面板；浏览器脚本负责面板、提交反馈及台词交互；CSS 负责布局和状态表现；Library 存储接口不变。

主路径：GET 文档 → 类型数据/公共关系 → 渲染 → 阅读或显式操作 → 既有写接口 → 刷新后展示结果。
失败路径：写接口拒绝/网络失败 → 原面板与输入保留 → 错误提示 → 修改或重试；媒体缺失/无产物由只读详情状态表达，不伪装可播放或成功。

## 7 模块

`src/web/views.ts` 公共与类型视图；`src/web/static/app.css` 详情局部规范；静态详情交互脚本与 `video-workbench.js`；必要时服务层只传递既有字段，不改变业务接口。其它类型通过现有布局兼容，不受详情专用选择器影响。

## 8 API/CLI

N/A：不新增或修改公共接口，保留现有文档、关联、标题、笔记、分析与深读请求契约。

## 9 边界

所有动态文本继续转义；高亮不能把台词当 HTML。模态焦点可达。不同文档的成功提示不串用。修订冲突与数据保护保留；关联与解除不改变媒体指纹、台词、批注或深读产物。无权限/执行错误保留现有后端拒绝。

## 10 迁移/兼容/回滚

无数据迁移。变更仅前端呈现，旧文档无需重分析；回退代码即可回到旧呈现，不回滚用户数据。具体部署只遵从项目已有运行手册，不推定日常服务允许重启。
