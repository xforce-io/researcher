## 用户入口（必须走）

1. Library → 三类详情 → 返回 Library：完整长标题、可读日期和公共操作，1366×768 桌面首屏可辨。
2. 三类详情「管理 topic 关联」：空状态、手选/推荐、保存、刷新、编辑理由、解除确认；成功提示和磁盘关系一致。受控故障通过临时使验证 topic 不可用，在已打开面板提交，确认错误保留输入，恢复后重试。推荐只填表单、不落关系。关闭按钮、Escape、取消编辑后回到内容及入口焦点；普通打开与编辑自动打开分别验证。
3. 视频「编辑标题」→ 输入 201 Unicode 码点 → 保存失败且原值不变 → 合法值保存 → 返回 Library 再开。保全 #194。
4. 视频搜索原文或中文台词 → 上下结果 → 点句 → 清空 → 无结果；词级高亮可见，时间定位正确，播放器与台词首屏可见。保全 #200 的可见结果；管理面板改为按需打开，不再要求表单占用页头。
5. 自主笔记「编辑笔记」→ 修改正文 → 保存 → 重开确认；paper 跳转文档批注，查看深读产物、可用深读入口及状态；视频查看分析入口/不可用原因，验证媒体缺失仍能搜索台词。
6. 窄屏检查三类公共入口可达、视频上下布局可读、无横向溢出。

## #207 S1–S5：阅读与操作层级

隔离 workspace 必须同时有 paper、blog、note、video。paper 含可跳转文档批注和足够长的深读正文（可连续滚动过一屏）。blog 至少可打开详情。桌面 1366×768；补窄屏 paper/blog 单列。

1. S1 批注锚点：打开 paper 与 blog 详情，点「文档批注」，「文档批注」标题首行完整露在固定顶栏下方，不被遮住。note、video 无批注入口；确认标题不被顶栏压住，且没有失效的 `#annotations` 跳转。
2. S2 操作主次：四类详情各看顶部操作。paper/blog：深读/重新深读为实心主按钮，「文档批注」为描边跳转，不得两个实心主按钮并列；note：编辑笔记为实心；video：视频分析为实心。无异常大型空白容器。每类执行一个可用操作（跳转、打开关联面板、或进入编辑）。
3. S3 深读运行态：在支持深读的文档上进入进行中、成功、失败。进行中默认是一行中文状态，正文仍可读，等宽英文步骤和运行日志不默认铺开（可在折叠「运行详情」内）。成功后无运行条；失败可重试。
4. S4 长文布局：打开长 paper，分别停在开头、中段、靠后，主栏可读，右栏不是与正文同高的空卡片墙；旁注在滚动中仍可见或仍承载集成/删除信息。
5. S5 信息层级：四类详情标题、操作、topic 关联、状态可区分。类型为论文/博客/自主笔记/视频；状态为中文；身份字段不用 `authors`/`none`/`read · 0 links` 这类英文串。批注类型为普通/澄清等中文。

保全：#203 的关联面板关闭/Escape 焦点由 `tests/web/document-topic-focus.test.ts` 覆盖，本票人工驾驶不重复 15 条焦点路径。#194 / #200 仅在本次改到视频工作台时复查。
